## Design System

### Color Palette
```
Primary: #0f766e (Teal)
Secondary: #1d4ed8 (Blue)
Accent: #06b6d4 (Cyan)
Dark: #0f172a (Navy)
Light: #f8fafc (Light Gray)
Text: #1e293b (Dark Gray)
Text Light: #64748b (Medium Gray)
Border: #e2e8f0 (Light Border)
Success: #10b981 (Green)
```

### Typography
- **Font Family**: System UI stack for optimal performance
- **Base Size**: 16px (17px body for readability)
- **Line Height**: 1.6 for comfortable reading
- **Heading Styles**: Progressive sizing from H1-H3

### Spacing System
- Consistent padding and margins based on multiples of 8px
- Section padding: 60-80px vertical
- Component gaps: 15-40px depending on context

### Component Patterns
- **Cards**: Borders, rounded corners, hover effects
- **Buttons**: Gradient backgrounds, hover transforms
- **Sections**: Background color alternation for visual separation
- **Grids**: Auto-fit responsive columns with consistent gaps

## How to Use

### Deploying the Website
1. Copy both HTML files to your web server
2. No database or backend required
3. Static files can be hosted anywhere (GitHub Pages, Netlify, etc.)

### Customization Options
- **Newsletter**: Update the form action to your email service (Brevo, Mailchimp, etc.)
- **Social Links**: Replace placeholder # links with actual social media URLs
- **Content**: Easy to edit tool descriptions and features
- **Images**: Can add actual screenshots or tool logos in tool cards

### Adding New Tools
1. Duplicate a tool card template
2. Update the tool name, category, and description
3. Modify features list and ratings
4. Update pricing and best-for information
5. Add link to tool website

### Extending Features
The modular CSS makes it easy to:
- Add new sections
- Create additional pages (blog, tutorials, etc.)
- Implement filtering and sorting
- Add user accounts and saved favorites
- Connect to a backend for dynamic content
